# ちゃちゃをAIと建てる / Building Chacha with AI

## この場所について / About This Project

AIコーディング未経験の非エンジニアが、家庭用AI「ちゃちゃ」をAIと一緒に開発してきた過程を、読み物として記録する場所です。

完成したコードの紹介ではなく、迷ったこと、決めたこと、失敗したこと、立て直したことを中心に残します。

## 公開するもの / What We Publish

- 開発が始まった経緯と、その後の物語
- 設計を考えるときに使った考え方
- 失敗から得た教訓
- 今後の方向性

## 公開しないもの / What We Do Not Publish

- 「ちゃちゃ」本体のソースコード
- 認証情報、個人情報、家庭内の非公開情報
- 安全性を損なうおそれのある詳細

## 表記方針 / Language Policy

見出しと項目名は日本語と英語を併記し、本文は日本語で記述します。

## 比喩について / About the Metaphor

筆者は施工管理の専門家ではなく、本リポジトリは実際の施工管理実務を正確に再現するものではありません。建築現場・施工管理の表現は、AIとの開発経験を説明するための比喩です。
